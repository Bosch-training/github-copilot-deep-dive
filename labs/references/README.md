# Reference Examples

Illustrative examples only — not part of the taught course content. Custom agents, agent skills,
hooks, and MCP servers are named but not taught in this course (see course-content.md, Assumption 7
and Module 5's "Where this goes next"). These files exist so a participant or facilitator who wants
to look further can see the actual shape of each file, verified against current GitHub Copilot
documentation.

- `example.instructions.md` — a path-specific custom instructions file (real destination:
  `.github/instructions/<name>.instructions.md`).
- `example.agent.md` — a custom agent definition (real destination:
  `.github/agents/<name>.agent.md`).
- `example-skill/SKILL.md` — an agent skill (real destination:
  `.github/skills/<skill-name>/SKILL.md`).
- `../copilot-instructions.md` — the repository-wide custom instructions file (real destination:
  `.github/copilot-instructions.md`), taught directly in Module 2 Exercise 2.
